# Online Marketplace

PHP project: catalog, search, cart, orders, user profile, admin panel.

## How to run
1. Install XAMPP and start Apache
2. Copy the project folder to xampp/htdocs/marketplace
3. Open http://localhost/marketplace/index.php

## Admin access
Register a user, then set "role": "admin" in data/users.json.

## Tech
HTML, CSS, PHP (sessions, JSON file storage)
